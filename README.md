# allamashraf-site

Allam Ashraf's static portfolio for GTM engineering, lead operations and automation.

Built with Astro. The current mobile upgrade is retained. Production hosting is GitHub Pages with the canonical domain allamashraf.dev.

Install with `npm ci`. Check with `npm run check` and `npm run test:unit`. Build with `npm run build:prod`, then run `npm run check:budgets`. Browser tests run with `npm test`; Lighthouse uses `npm run lhci`.

See `docs/RELEASE_CHECKLIST.md` for current verification results and remaining launch requirements. Public deployment is manual through GitHub Actions. Email stays hidden until forwarding is tested.
